# InnerStock frontend

React 19 + Vite. See the [main README](../README.md) for what the app does and how to run it, and [`CLAUDE.md`](../CLAUDE.md) for architecture notes.

```bash
npm install
npm run dev     # http://localhost:5173 (expects the backend on http://127.0.0.1:8000)
npm run lint
npm run build   # set VITE_API_URL to point the build at another API
```
